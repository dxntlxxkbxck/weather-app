# Weather App

Клиентское веб-приложение для просмотра погодных данных и прогноза на ближайшие дни. Проект выполнен на HTML5, CSS3 и JavaScript без серверной части и может использоваться как учебная курсовая работа по разработке клиентского веб-приложения.

![Превью интерфейса](src/preview.gif)

## Возможности

- поиск погоды по названию города;
- отображение текущей температуры, описания погоды, влажности, ветра и вероятности осадков;
- прогноз на 5 ближайших дней;
- динамическая смена фонового изображения по сезону и погодным условиям;
- сохранение последних 10 городов в `localStorage`;
- повторный поиск по клику на город из истории;
- валидация пользовательского ввода;
- сообщения о загрузке, успешном обновлении и ошибках API;
- адаптивная вёрстка для мобильных экранов.

## Технологии

- HTML5;
- CSS3;
- JavaScript ES6+;
- Fetch API;
- Web Storage API (`localStorage`);
- OpenWeatherMap API;
- Boxicons;
- Google Fonts.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
3. При загрузке автоматически отображается погода для Санкт-Петербурга.
4. Введите город в поле поиска и нажмите `Найти` или клавишу Enter, например: `Москва`, `Сочи`, `Yakutsk`.

Для работы приложения нужен доступ к интернету, потому что данные загружаются из OpenWeatherMap API.

## API

Приложение использует endpoint прогноза OpenWeatherMap:

```text
https://api.openweathermap.org/data/2.5/forecast
```
API предоставляет прогноз с интервалом 3 часа. Для отображения основных погодных данных используется ближайшая доступная временная точка прогноза.

Основные параметры запроса:

- `q` - название города;
- `appid` - API-ключ;
- `units=metric` - температура в градусах Цельсия;
- `lang=ru` - описание погоды на русском языке.

API-ключ указан в файле `index.js`:

```js
const apiKey = '...';
```

## Логика работы

1. При загрузке страницы вызывается `fetchWeatherData('Saint Petersburg, RU')`.
2. Функция формирует запрос к OpenWeatherMap API через `fetch`.
3. После успешного ответа обновляются элементы DOM: дата, город, температура, описание, детали погоды и прогноз.
4. Скорость ветра переводится из метров в секунду в километры в час.
5. Функция `changeSeasonalBackground()` выбирает сезонный фон по месяцу и погодному состоянию.
6. История поиска сохраняется в `localStorage` в ключе `weatherHistory`.
7. При повторном открытии приложения история восстанавливается и отображается в интерфейсе.

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
| --- | --- |
| Поиск `Москва` | Отображается текущая погода и прогноз для Москвы |
| Поиск `Сочи` | Фон и погодные данные обновляются без перезагрузки страницы |
| Поиск `Yakutsk` | Корректно обрабатывается название города, введённое латиницей |
| Пустой ввод | Приложение показывает предупреждение и не отправляет запрос |
| Ввод цифр или спецсимволов | Валидация блокирует некорректный запрос |
| Повторный поиск города | В истории не создаётся дубль, город перемещается в начало |
| Недоступный API | Отображается сообщение об ошибке загрузки |

## Ограничения

- приложение зависит от доступности OpenWeatherMap API;
- при блокировке внешних запросов данные не обновятся;
- прогноз формируется на основе данных API с шагом 3 часа;
- история поиска хранится локально в браузере пользователя.
